# Real-Time Digital Filter Evaluation Platform

## Description

A platform for designing, testing, and evaluating digital filters on embedded systems in real time.

The ESP32 acts as a configurable function generator, data acquisition unit, and communication gateway. Test signals generated by the ESP32 are fed to a target microcontroller (STM32), where a digital filter is executed. The filtered output is sampled and streamed back to the ESP32 for visualization and analysis through a web-based interface.

The system supports filter configuration, coefficient updates, and real-time monitoring of filter performance.

## Functional Flow

1. ESP32 generates a test signal through its DAC.
2. STM32 samples the signal using its ADC.
3. STM32 processes the signal using the selected digital filter.
4. STM32 outputs the filtered signal through its DAC.
5. ESP32 samples both reference and filtered signals.
6. Data is streamed over UDP to a host application.
7. A web-based GUI visualizes filter behavior in near real time.
